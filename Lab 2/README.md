# Lab 2 
This folder contains the C program exercises completed for Lab 2. 

## Programs 
- hello.c
- hello_error.c
- input.c
- return50.c
- success.c
- userinfo.c

## Description
These programs demonstrates basic C programming concepts, including program execution, input/output, return values, and handling simple errors.

## Compilation
Compile an individual program with:

gcc filename.c -o filename

then run it with:
./filename
