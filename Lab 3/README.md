# Lab 3: Investigating Process Lifecycles and OS Interaction

## Module 
ST5003CMD Operating Systems, Security, And Networks

## Lab Overview
This lab invistigates how C programs interact with the Linux operating system through process management, process identity, exit status, standard input/output, and conditional execution.

## Tasks
- Task 1: The Long-Running Process
- Task 2: Process Identity (PID and PPID)
- Task 3: Exit Codes
- Taks 4: Standard I/O Streams
- Task 5: Conditional Execution and Termination
